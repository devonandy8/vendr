# Vendr

Public website for **Vendr**, the campus marketplace app.

This folder is a static HTML, CSS, and JavaScript site. It includes a working demo catalog, waitlist, support form, privacy policy, and terms.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## GitHub Pages

The live site is published from this directory’s contents at the repository root.
